# DeskConnect 帮助

欢迎使用 DeskConnect（基于 Deskflow 的键鼠共享工具）。

## 简介

DeskConnect 让一台电脑的键盘和鼠标控制同一局域网内的其他电脑，并支持剪贴板与文件传输。

- 一端作为**服务器**（接键盘鼠标的主机）
- 其他机器作为**客户端**并连接到服务器

## 快速开始

1. 在主机上选择「使用此计算机的键盘和鼠标」，配置屏幕布局后点击启动。
2. 在另一台电脑上选择「使用另一台计算机的鼠标和键盘」，填写主机 IP 或名称后连接。
3. 将鼠标移到屏幕边缘即可切换到另一台电脑。

## 常用功能

### 文件传输

- 菜单「文件 → 发送文件」可向已连接的客户端发送文件。
- 设置里可配置接收目录、单次最大大小（单位 MB，例如 10240 ≈ 10 GB）。
- 服务器默认开启限速以保持键鼠流畅（两端发送都限速）；传输中可点「本次不限速」（会先等待对方确认）。

### 鼠标定位

设置里默认开启「定位鼠标」：按下绑定的定位键（默认中键）时，当前光标所在电脑上会出现短暂定位动画（默认涟漪扩散），方便在多台电脑间找到鼠标。可在设置中选择样式（缩小圆圈、涟漪、十字准星、光斑、脉冲、闪烁圆点），并点击绑定框重新指定鼠标侧键、任意键或组合键（左键与 Esc 不可绑定；绑定过程中按 Esc 取消）。定位键本身仍会传给当前程序。

### Windows 右键发送

设置 → 文件传输 → 勾选「添加到资源管理器右键菜单」后，可对单个文件右键「用 DeskConnect 发送」。多台已连接电脑时会弹出选择目标。

### Windows 防火墙

设置 → 网络 →「允许通过 Windows 防火墙」：一键添加入站规则（程序 + TCP 端口），需管理员确认。

### Windows 全屏

服务器配置中可勾选「全屏时禁用键鼠共享」（默认关闭）：开启后，本机全屏游戏/视频时鼠标不会滑到另一台。

### 主题

设置 → 主题：浅色 / 深色（标题栏随软件主题，不跟系统）。

### 日志

「视图」菜单可打开或关闭日志面板（默认关闭）。
