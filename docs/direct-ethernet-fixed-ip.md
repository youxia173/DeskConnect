# 固定网线直连地址

两台电脑用一根网线直接连接时，不需要路由器、互联网或 DHCP。Linux、Windows 两端勾选“网线直连”后，服务端使用 `169.254.248.1/16`，客机使用 `169.254.248.2/16`；客机自动填入服务端地址 `169.254.248.1`。系统可能要求授权在各自的有线网卡上添加地址，地址准备好后才启动相应的连接。

程序只选已连接且未接入其它网络的物理有线网卡。有默认网关，或已有普通局域网 IPv4、全局 IPv6 地址的网卡不会用于直连。如果没有合适的有线网卡，勾选操作会被拒绝；可以插入另一块专用于直连的有线网卡后重试。判断依据是本机网卡地址和路由配置，无法单独证明网线上只有这两台电脑。

Linux 用 `ip address add` 添加地址；Windows 用提权的短时进程调用系统网络接口添加临时地址，并等待地址冲突检测完成。这些操作不更改原来的 DHCP 或默认网关。取消勾选会恢复软件原来的绑定设置，但不会删除已添加的系统地址，避免误删其他进程后续沿用的地址。Linux 可在确认网卡名称后用 `sudo ip address del 169.254.248.1/16 dev <网卡名>` 或 `sudo ip address del 169.254.248.2/16 dev <网卡名>` 移除；Windows 可重启网卡清除临时地址。

两台电脑不能使用相同的直连地址。防火墙仍需允许软件使用的服务端端口。代码本次未编译，也未进行双机实测。
